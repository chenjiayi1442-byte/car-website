# Drive Motion

A modern car dealership landing page built with HTML, CSS, and JavaScript.

## Features
- Premium dark luxury theme
- Responsive layout for desktop and mobile
- Filterable vehicle inventory cards
- Service, testimonial, and contact sections
- CTA-focused design for a car dealership brand

## Run locally
Open `index.html` in a browser, or serve the folder with a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
